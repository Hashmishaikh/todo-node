# Todo API - Frontend Integration Documentation

Welcome! This document provides all the details required to integrate the Todo API with any frontend client (React, Vue, Angular, Next.js, mobile app, etc.).

---

## 1. General Information

- **Base URL:** `http://localhost:8080/api/todos` (or your production domain)
- **Health Check Endpoint:** `GET http://localhost:8080/`
- **Default Headers:**
  ```http
  Content-Type: application/json
  Accept: application/json
  ```
- **CORS:** Enabled for all origins by default.

---

## 2. Todo Data Model

| Field | Type | Required | Default | Allowed Values / Notes |
|---|---|---|---|---|
| `_id` | `String` | Auto | Generated by MongoDB | Unique identifier (e.g., `"6701a5b8e91f42a1b2c3d4e5"`) |
| `title` | `String` | **Yes** | — | Non-empty string, max 100 characters |
| `description`| `String` | No | `""` | Optional details or notes |
| `completed` | `Boolean` | No | `false` | `true` or `false` |
| `priority` | `String` | No | `"medium"` | `"low"` \| `"medium"` \| `"high"` |
| `dueDate` | `String` (ISO Date) | No | `null` | ISO 8601 Date string (e.g., `"2026-10-15T00:00:00.000Z"`) |
| `createdAt` | `String` (ISO Date) | Auto | Current timestamp | Creation date |
| `updatedAt` | `String` (ISO Date) | Auto | Current timestamp | Last updated date |

---

## 3. Endpoints Overview

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/todos` | Get all todos (with optional filtering & search) |
| `GET` | `/api/todos/:id` | Get a single todo by ID |
| `POST` | `/api/todos` | Create a new todo |
| `PUT` | `/api/todos/:id` | Update an existing todo |
| `PATCH` | `/api/todos/:id/toggle` | Toggle completion status (`true` <-> `false`) |
| `DELETE` | `/api/todos/:id` | Delete a todo |

---

## 4. Endpoint Details

### 4.1. Get All Todos

- **URL:** `/api/todos`
- **Method:** `GET`
- **Query Parameters (Optional):**
  - `completed` (`true` | `false`): Filter by completed status.
  - `priority` (`low` | `medium` | `high`): Filter by priority.
  - `search` (`string`): Search by title (case-insensitive substring match).

#### Example Request:
```http
GET /api/todos?completed=false&priority=high&search=groceries
```

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "count": 1,
  "data": [
    {
      "_id": "6701a5b8e91f42a1b2c3d4e5",
      "title": "Buy groceries",
      "description": "Milk, Eggs, Bread",
      "completed": false,
      "priority": "high",
      "dueDate": "2026-10-15T00:00:00.000Z",
      "createdAt": "2026-10-05T08:22:15.123Z",
      "updatedAt": "2026-10-05T08:22:15.123Z"
    }
  ]
}
```

### 4.2. Get Single Todo by ID

- **URL:** `/api/todos/:id`
- **Method:** `GET`

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "data": {
    "_id": "6701a5b8e91f42a1b2c3d4e5",
    "title": "Buy groceries",
    "description": "Milk, Eggs, Bread",

    "createdAt": "2026-10-05T08:22:15.123Z",
    "updatedAt": "2026-10-05T08:22:15.123Z"
```

```json
{
  "success": false,
  "message": "Todo not found with id of 6701a5b8e91f42a1b2c3d4e5"
}
```

---

### 4.3. Create a Todo

- **URL:** `/api/todos`
- **Method:** `POST`
- **Headers:** `Content-Type: application/json`

#### Request Body:
```json
{
  "title": "Finish portfolio website",
  "description": "Add dark mode and contact form",
  "completed": false,
  "priority": "high",
  "dueDate": "2026-10-20"
}
```
*(Only `title` is strictly required. All other fields are optional.)*

#### Success Response (`201 Created`):
```json
{
  "success": true,
  "message": "Todo created successfully",
  "data": {
    "_id": "6701b7a2e91f42a1b2c3d4e6",
    "title": "Finish portfolio website",
    "description": "Add dark mode and contact form",
    "completed": false,
    "priority": "high",
    "dueDate": "2026-10-20T00:00:00.000Z",
    "createdAt": "2026-10-05T08:35:10.450Z",
    "updatedAt": "2026-10-05T08:35:10.450Z"
  }
}
```

#### Error Response (`400 Bad Request`):
```json
{
  "success": false,
  "message": "Please provide a todo title"
}
```

---

### 4.4. Update a Todo

- **URL:** `/api/todos/:id`
- **Method:** `PUT`
- **Headers:** `Content-Type: application/json`

#### Request Body:
Send only the fields you wish to update:
```json
{
  "title": "Finish portfolio website v2",
  "description": "Updated scope: add blog page too",
  "priority": "medium",
  "completed": true
}
```

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "message": "Todo updated successfully",
  "data": {
    "_id": "6701b7a2e91f42a1b2c3d4e6",
    "title": "Finish portfolio website v2",
    "description": "Updated scope: add blog page too",
    "completed": true,
    "priority": "medium",
    "dueDate": "2026-10-20T00:00:00.000Z",
    "createdAt": "2026-10-05T08:35:10.450Z",
    "updatedAt": "2026-10-05T08:42:00.120Z"
  }
}
```

---

### 4.5. Toggle Todo Status (Quick Action)

- **URL:** `/api/todos/:id/toggle`
- **Method:** `PATCH`
- **Headers:** Not required (No body needed)

Inverts the `completed` value (`false` becomes `true`, `true` becomes `false`).

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "message": "Todo marked as completed",
  "data": {
    "_id": "6701b7a2e91f42a1b2c3d4e6",
    "title": "Finish portfolio website",
    "completed": true,
    "updatedAt": "2026-10-05T08:45:00.000Z"
  }
}
```

---

### 4.6. Delete a Todo

- **URL:** `/api/todos/:id`
- **Method:** `DELETE`

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "message": "Todo deleted successfully",
  "data": {}
}
```

#### Error Response (`404 Not Found`):
```json
{
  "success": false,
  "message": "Todo not found with id of 6701b7a2e91f42a1b2c3d4e6"
}
```

---

## 5. Standard Error Format

All error responses from this API follow a consistent schema:

```json
{
  "success": false,
  "message": "Error description goes here"
}
```

### Common HTTP Status Codes:
- `200 OK` — Successful GET, PUT, PATCH, DELETE
- `201 Created` — Successful POST (resource created)
- `400 Bad Request` — Missing or invalid required fields
- `404 Not Found` — Resource doesn't exist or route not found
- `500 Internal Server Error` — Server issue

## 6. Frontend Quick-Start Code Snippets

### Using `fetch` (JavaScript):

```javascript
const BASE_URL = 'http://localhost:5001/api/todos';

// 1. Fetch all todos
export const fetchTodos = async (filters = {}) => {
  const query = new URLSearchParams(filters).toString();
  const url = query ? `${BASE_URL}?${query}` : BASE_URL;
  const res = await fetch(url);
  return res.json();
};

// 2. Create todo
export const addTodo = async (todoData) => {
  const res = await fetch(BASE_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(todoData),
  });
  return res.json();
};

// 3. Toggle todo completion
export const toggleTodo = async (id) => {
  const res = await fetch(`${BASE_URL}/${id}/toggle`, {
    method: 'PATCH',
  });
  return res.json();
};

// 4. Update todo
export const updateTodo = async (id, updatedFields) => {
  const res = await fetch(`${BASE_URL}/${id}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(updatedFields),
  });
  return res.json();
};

// 5. Delete todo
export const deleteTodo = async (id) => {
  const res = await fetch(`${BASE_URL}/${id}`, {
    method: 'DELETE',
  });
  return res.json();
};
```

### Using `axios`:

```javascript
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:5001/api/todos',
  headers: { 'Content-Type': 'application/json' },
});

export const getTodos = (params) => api.get('/', { params });
export const getTodoById = (id) => api.get(`/${id}`);
export const createTodo = (data) => api.post('/', data);
export const updateTodo = (id, data) => api.put(`/${id}`, data);
export const toggleTodo = (id) => api.patch(`/${id}/toggle`);
export const deleteTodo = (id) => api.delete(`/${id}`);
```
